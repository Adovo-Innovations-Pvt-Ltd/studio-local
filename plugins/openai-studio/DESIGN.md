# Studio Local logo direction

User direction: Studio Local; simple, minimal, better color and no AI-generated
logo aesthetic. Antislop applies during design. This records the interpretation
of that brief, not a claim that the user specified the exact font or color.

Reading this as a quiet typographic identity for a local utility used by
creators in Codex. ENERGY 1 / RHYTHM 1 / MOTION 1.

- Motif: lowercase `sl` uses the supplied name's initials without adding a
  metaphor that competes with a small plugin-list label.
- Typography: Helvetica Neue Medium, typeset locally with macOS CoreText and
  converted to filled SVG outlines. No font file is distributed or required
  at runtime. The mark is typeset artwork, not an image-model output.
- Composition: the two glyphs are centered as one unit; a wide perimeter gives
  the app icon a single focus. Transparent composer variants enlarge the same
  outlines so the letters stay visible at small sizes.
- Blue #3158B7: a restrained, flat color distinguishes the utility in a plugin
  list without gradients, extra accent colors or effects.
- White #FFFFFF: the reversed mark is clear on the blue app tile and on dark
  host surfaces. Neutral #181B22 supplies a one-color light-surface version.
- Surface: one rounded app tile follows the icon format. Composer variants
  have transparent backgrounds and no additional container.
- Motion: none, because this is a static identity.

This is an AI-assisted vector/typesetting revision. No prompt or asset was sent
to an image-generation service. Similarity and trademark clearance are not
established by a visual quality check.
